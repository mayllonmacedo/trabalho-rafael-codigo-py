# trabalho-rafael-codigo-py


Este repositório contém um script desenvolvido para a disciplina de Banco de Dados e Programação.

## Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Conceitos Praticados:** Listas, dicionários, estruturas condicionais e laços de repetição.

## Como Executar o Script

1. Certifique-se de ter o Python 3 instalado em seu computador.
2. Baixe ou clone este repositório.
3. Abra o terminal ou prompt de comando.
4. Execute o seguinte comando:

```bash
python script.py
```

## Objetivo do Projeto

O programa tem como objetivo organizar e filtrar as notas dos alunos, identificando aqueles que foram aprovados e reprovados.

A média mínima para aprovação é 7.0.

## Funcionamento

O programa utiliza uma lista de dicionários para armazenar os nomes e as notas dos alunos.

Por meio de estruturas condicionais e laços de repetição, separa os alunos em dois grupos:

- **Aprovados:** alunos com nota maior ou igual a 7.
- **Reprovados:** alunos com nota inferior a 7.
